# CyberQuiz
Projeto final de Programação Web em JavaScript — Senac DF.

## Objetivo
Ensinar conceitos básicos de segurança digital por meio de cinco perguntas interativas.

## Como executar
Abra index.html no navegador. Não há dependências externas.

## Tecnologias
HTML (estrutura), CSS (visual responsivo), JavaScript (eventos, DOM, funções, condicionais, arrays, objetos, laços e localStorage).

## Funcionalidades
- Validação quando nenhuma resposta é selecionada.
- Feedback imediato de acerto ou erro.
- Pontuação, progresso, recorde local e reinício.

## Publicação
Crie um repositório público chamado cyberquiz, envie os arquivos index.html, estilo.css, script.js e README.md na raiz. Em Settings > Pages, selecione Deploy from a branch, main, / (root), Save. Confira o endereço publicado e teste em celular e computador.

## Transparência
A versão inicial foi gerada com auxílio do ChatGPT. Revise, execute e compreenda o código antes de apresentar. Registre apenas as contribuições humanas e o uso de outras ferramentas que realmente ocorrerem.
